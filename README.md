# Three-LAN Network Design & Static Routing

## Project Overview

This project is a Cisco Packet Tracer lab demonstrating connectivity between three separate IPv4 LANs using three routers and static routing.

The topology was designed and simulated in Cisco Packet Tracer as part of hands-on networking practice. The lab focuses on IPv4 addressing, router-to-router connectivity, static routes, and end-to-end connectivity testing.

## Objectives

- Build a network containing three separate LANs.

- Configure IPv4 addressing for PCs and router LAN interfaces.

- Connect the three routers through two point-to-point networks.

- Use static routing to provide communication between the LANs.

- Test end-to-end connectivity between hosts.

- Practice identifying successful and failed connectivity tests in Packet Tracer Simulation Mode.


## Network Topology

The lab contains:

- 3 routers

- 3 switches

- 10 PCs

- 3 LAN segments

- 2 router-to-router links

- IPv4 addressing in the 192.168.x.0 and 10.x.x.x ranges.
